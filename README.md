
# Paint My Home VR

An immersive virtual reality interior-design experience that
allows users to explore a home environment and select colors
using an interactive VR interface.

## Project Preview

![Paint My Home VR](paint-my-home-vr.png)

## Features

- Interactive VR color-selection panel
- Real-time interior color customization
- Immersive virtual home environment
- Hand/controller-based interaction

## Technology

- Unity
- C#
- Virtual Reality
